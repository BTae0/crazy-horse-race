# 엽기 경마

말들이 달리다가 넘어지고, 뒤로 가고, 두 발로 일어서는 복불복 경마 웹 게임입니다. 순위는 돌발 사건이 좌우합니다.

- 말 수 2~12마리 선택, 말마다 다른 색과 번호
- 돌발 사건 10종: 넘어짐, 뒤로 달리기, 두 발 달리기, 로켓 점프, 졸기, 유턴, 백플립, 바나나 미끄러짐, 날개 비행, 순간이동
- 옆 레인 난투극: 옆 레인의 말에게 싸움을 걸고, 진 말은 K.O.로 쓰러졌다가 일어나 다시 달림
- 옆면 2D 레인별 경주, 실시간 순위와 결과 화면
- 배속 1x/2x/4x, 일시정지, 결과 바로 보기

## 실행

```
npm install
npm run dev      # 개발 서버
npm test         # 시뮬레이션 테스트
npm run build    # dist/ 생성
```

기술 스택: Vite, TypeScript, Canvas 2D(말은 코드로 그림), Vitest
