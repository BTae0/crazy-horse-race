# 엽기 경마 설계서

작성일: 2026-10-15 / 용도: 개인용 / 위치: `C:\AI\crazy-horse-race\`

## 1. 목표와 범위

- 말들이 달리다가 엽기적인 돌발 사건(넘어짐, 뒤로 달리기, 두 발 달리기 등)을 겪으며 순위가 뒤바뀌는 복불복 경마 게임.
- 확정 요구: ① 말 수 선택(2~12) ② 말마다 다른 색 ③ 경마 진행 ④ 엽기 돌발 모션.
- 시점: 옆면 2D, 레인별 가로 경주. 관전 전용(말 고르기/베팅 없음).
- 제외(2차): 효과음, 베팅, 3D.
- 개인용, 로컬 정적 웹 앱(Artifact 미사용). 원본 참고 코드 없음(전부 신규 작성).

## 2. 기술 스택

Vite + TypeScript, Canvas 2D(말은 코드로 그림), Vitest. 실행 환경 Node.js v24.

## 4. 경주 규칙 (race.ts)

- 트랙 700 m, 기본 속도 16 m/s에 말별 ±1.5 % 편차(순위는 사건이 좌우).
- 말은 평소 `run` 상태이며, 쿨다운(사건 종료 후 2초)이 끝나면 초당 0.14 확률로 사건이 발동한다.
- 사건이 끝나면 `run`으로 복귀한다. 사건은 모두 지속시간이 유한하고 평소 속도는 항상 양수이므로 전원 완주가 보장된다.
- 위치는 0 m 아래로 내려가지 않는다. 결승선(700 m)을 넘으면 도착 순위를 확정한다. 도착 시각은 스텝 구간(1/60초) 안에서 보간하며, 같은 스텝에 넘으면 도착 시각이 빠른 말이 먼저다.
- 도착한 말은 속도를 기본 속도 이하로 제한하고 서서히 감속하며 결승선 너머로 달린다. 순간이동으로 도착해도 결승선 너머 5 m로 제한한다.
- 전원이 도착하면 경주가 끝난다. 같은 시드는 같은 경주를 재현한다.

### 돌발 사건 10종

| 종류 | 효과 |
|---|---|
| trip 넘어짐 | 0.7초 미끄러지다 정지, 1.8~2.8초 |
| moonwalk 뒤로 달리기 | 속도 -0.7배, 2~3초 |
| biped 두 발 달리기 | 속도 0.6~1.6배(무작위), 2~3.5초 |
| rocket 로켓 | 속도 2.4배, 1.3~1.8초 |
| nap 졸기 | 정지, 1.8~3초 |
| uturn 유턴 | 속도 -0.9배, 1.2~2초 |
| backflip 백플립 | 1.0~1.2초에 걸쳐 25~50 m 도약 |
| banana 바나나 | 속도 -1.2~2.6배(무작위), 1.2~2초 |
| wings 날개 | 속도 1.7배, 2~3초 |
| warp 순간이동 | 즉시 ±30~80 m 이동, 0.8초 정지 |

### 옆 레인 난투극 (2026-10-15 추가)

- 사건이 발동될 때 30 %는 난투극을 시도한다. 인접 레인에 평소 상태이고 18 m 이내인 말이 있고 둘 다 결승선까지 60 m 이상 남았을 때만 성립하며, 아니면 위 10종 중 하나가 발동한다.
- 시작 0.5초 동안 두 말이 만나는 지점으로 모이고(공격한 말은 옆 레인으로 0.7 레인만큼 넘어감), 2.0~2.6초간 기본 속도의 약 0.6배로 달리며 싸운다.
- 결과는 50 : 50 무작위다. 진 말은 0.4초간 뒤로 튕겨 나간 뒤 쓰러져(K.O.) 총 1.6~2.2초 뒤 일어나 다시 달리고, 이긴 말은 1.2초간 속도 2.4배로 포효한다. 가장자리 레인이 싸움에 덜 휘말려 유리해지지 않도록 난투극의 평균 손익을 0에 가깝게 맞췄다(6마리 3000경주 기준 레인별 우승률 16.0~18.0 %). 공격한 말의 레인 이동은 이후 0.3초 안에 원래 레인으로 돌아온다.
- 사건이 발동하면 내부 기록(commentary)에 남기며, 화면에는 해설 자막을 표시하지 않는다(2026-10-15 요청으로 제거).

## 5. 화면

- 설정: 말 수 슬라이더(2~12, 기본 6, 마지막 선택 기억), 색 미리보기 칩, Start.
- 경주: 3·2·1 카운트다운 → 경주. 하늘·관중석 영역을 화면 높이의 22 %로 줄여 레인을 넓히고, 말 크기는 레인 높이의 1.6배(최대 240 px)로 크게 그린다. 카메라는 선두~꼴찌 구간이 보이도록 가로 스크롤/줌, 레인별 말, 안장에 번호.
- HUD: 실시간 순위(좁은 화면·낮은 화면에서는 "순위" 버튼으로 열기), 상단 전체 진행 바(말별 색 점), 배속 1x/2x/4x, 일시정지, 설정으로.
- 첫 말 도착 후 전원 도착 전까지만 "결과 바로 보기" 버튼이 나타난다. 카운트다운 중 일시정지하면 카운트다운도 멈춘다. 결과 화면이 뜨면 경주 화면은 비활성(inert)이고 포커스는 "다시 달리기"로 이동한다. 전원 도착 시 결과 화면(순위표, 말별 사건 횟수, 다시 달리기, 설정으로).
- 말 색은 12색: 빨강, 파랑, 초록, 노랑, 보라, 주황, 분홍, 하늘, 갈색, 회색, 연두, 청록.

## 6. 테스트와 완료 기준

- 시뮬레이션: 말 2~12마리 전원 완주, 같은 시드는 같은 결과, 다른 시드는 다른 결과, 사건 10종이 모두 발생, 경주 시간 평균 35~65초, 위치 0 이상, 우승 분포가 한 말에 쏠리지 않음.
- 브라우저(Chrome): 설정 → 경주 → 결과.
- 완료 기준: 테스트 통과, `npm run dev`/`build` 성공, 390 px 폭에서 화면 유지.
